# Modularity on the Karate Club Graph
Course: DSC212 - Graph Theory

This repository contains a Jupyter notebook implementing recursive spectral modularity
partitioning on the Zachary Karate Club network. It implements the modularity matrix, the
leading-eigenvector split, recursive bisection stopping rule (λ₁ ≤ 0), and visualizations
with centrality/clustering metrics tracked across iterations.

Files:
- DSC212_Karate_Modularity.ipynb : main notebook (runs top-to-bottom)
- assets/ : generated layout and plot images

How to run:
1. Clone the repo.
2. Create a Python environment with `numpy`, `scipy`, `networkx`, `matplotlib`.
3. Open DSC212_Karate_Modularity.ipynb in Jupyter and run all cells.
